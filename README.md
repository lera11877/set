                 Опис проєкту


Мета
Цей репозиторій створено для демонстрації практичних навичок роботи з системою контролю версій Git та віддаленим сервісом GitHub. Основна мета — виконати всі вимоги навчального завдання, включаючи налаштування SSH-зв'язку, роботу з гілками та оформлення документації.

---

Функціонал
* Контроль версій: Ведення змістовної історії комітів.
* Структура: Мінімальна структура проєкту (/docs, /.gitignore).
* Співпраця: Демонстрація роботи з окремою гілкою (update) та об'єднання змін через Pull Request.
* Налаштування: Коректна конфігурація файлу виключень (.gitignore).
---
Тестувала роботу з гілками та з GitHub і VSCode

--
Інструкція Запуску


1.  Клонування репозиторію (через SSH):
    git clone git@github.com:lera11877/set.git 
    
2.  Перехід у папку:
    cd practice
    
3.  Перегляд історії:
    git log --oneline
